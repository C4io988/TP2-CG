# Sons para escutar

Abra `ouvir.html` ou os arquivos `.ogg` diretamente no seu player.
`cry` é o grito do Pokémon; `ambient` é a vocalização ambiente.

São os sons originais de Slowpoke, Shellder e Slowbro do pacote Cobblemon 1.7.3.
Não são carregados ou reproduzidos pela cena.

O pacote disponível não contém um som específico de transformação/evolução.
Nenhum som substituto foi criado ou baixado.

Origem: `Recursos Pokemon/assets/cobblemon/sounds/pokemon/`.
